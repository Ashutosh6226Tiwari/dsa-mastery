### 📜 Problem Description

Given a string  **s** , reverse the string.

**Examples:**

```
Input: s = "Geeks"
Output: "skeeG"

```

```
Input: s = "for"
Output: "rof"
```

```
Input: s = "a"
Output: "a"
```
